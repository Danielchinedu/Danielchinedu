# GitHub Growth Plan

This profile focuses on genuine engineering activity rather than artificial repository or commit volume.

## Priorities

- Build useful open-source software
- Ship documented features
- Use issues and pull requests for meaningful changes
- Add automated checks with GitHub Actions
- Publish tagged releases when projects reach stable milestones
- Encourage real contributors and community feedback

## Engineering Standards

Every flagship project should aim for:

1. Clear README and setup instructions
2. Sensible project structure
3. Tests for important behavior
4. Continuous integration
5. Issue templates and contribution guidance
6. Security-conscious configuration
7. Changelog and semantic versioning

## Achievement Principle

GitHub achievements should come from real development and collaboration. No fake stars, spam activity, or misleading contribution history.
